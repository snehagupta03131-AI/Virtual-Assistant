# Virtual Assistant

A simple Python-based Virtual Assistant that can perform basic tasks using voice commands.

## Features

* 🎤 Takes voice commands from the user
* 🔊 Responds using text-to-speech
* 🎵 Can play music
* 🌐 Can perform basic web-related tasks
* 💬 Provides simple voice-based interaction

## Technologies Used

* Python
* Speech Recognition
* Text-to-Speech
* Jupyter Notebook

## Project Files

* `virual_ass.ipynb` — Main Virtual Assistant implementation
* `music.py` — Music-related functionality
* `.gitignore` — Ignores unnecessary files

## How to Run

1. Clone this repository.
2. Open `virual_ass.ipynb` in Jupyter Notebook.
3. Install the required Python libraries.
4. Run the notebook cells.
5. Give voice commands and interact with the Virtual Assistant.

## Purpose

This project was created to understand Python automation, voice recognition, text-to-speech, and basic virtual assistant functionality.
